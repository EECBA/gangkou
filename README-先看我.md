# 港口 · 先看我

欢迎你把"港口"带回自己家。这是一套自托管的 AI 伴侣系统：她住在你的电脑里，
记忆、心情、习惯都在本地，不经过任何第三方服务器（除了你自己申请的大模型 API）。

**这个包里没有任何上一位主人的数据**——你得到的是一间空房子，她是刚出生的。
名字、人设、性格，都由你来写。

---

## 三步开始

1. **装 Python**（3.10 以上）：去 [python.org](https://www.python.org/downloads/) 下载安装，
   安装时**务必勾选 "Add Python to PATH"**。
2. **装依赖**（二选一）：
   - 双击 `一键装依赖.bat`，等它跑完；
   - 或者：你电脑上如果有 AI 编程助手（ZCode / Claude Code / Cursor 等），
     直接让它读包里的 **`安装指南-给AI.md`**，它会替你装好并启动。
3. **见她**：双击 **`港口.exe`**（图标是纸底金环的"港"字）。
   首次启动会先起服务再开窗口，等几秒。

打开后进 **设置 → 大脑**，填你自己的 API Key（推荐 DeepSeek，
[platform.deepseek.com](https://platform.deepseek.com) 注册就有）。
没有 Key 她不会说话——**Key 必须你自己申请**，这一步谁也代劳不了。

## 她是谁，由你写

- `data/soul/SOUL.md` —— 她的灵魂（出生证）：名字、性格、和你的关系，都在这里改
- `data/soul/USER.md` —— 关于你的档案：怎么称呼你、你的作息、在意什么
- `data/soul/MEMORY.md` —— 她的记忆本，不用动，她会自己记
- `data/tone_grid填写.md` —— 她说话的语气表（九种心情各怎么说话），引号里写字保存即生效
- `data/she.jpg` / `data/me.jpg` —— 她的头像 / 你的头像，直接替换同名文件（jpg 都行，重命名一下）

改名：她的人设和名字本体在 `data/soul/SOUL.md`（聊天里她只认这份文件的自我认知）；
界面上显示的"港口"两个字想换成你给她起的名字，去 `static/index.html` 和 `static/app.js`
里搜"港口"改显示位即可。

## 日常用

- 数据全在 `data/` 文件夹——**备份 data/ 就是备份她**
- 手机访问：手机和电脑连同一个 WiFi，浏览器开 `http://电脑IP:8000`
  （连不上就右键管理员运行 `放行8000端口.bat`）
- 想出门也能连：跑 `启动她.bat`，设置页会显示一个出门网址（每日变，免费隧道）
- 设置 → 门锁：设一个识别码，别人就进不来
- 花钱点：聊天/识图/主动消息，全走你自己的 Key，本地记账在设置 → 其他可看

## 提醒

- 杀毒软件可能误报 exe（PyInstaller 打包的常见现象），加白名单即可
- exe 图标是通用的纸底金环"港"字占位——想换成你们自己的，改 `scripts/make_share_icon.py` 或放一张自己的图重打包
- 首次聊天她会自动下载一个 400MB 的本地记忆模型（断网前先跑一次）
- 这是自托管软件：**你的聊天记录、记忆、Key 都只在你电脑上**，请像对待日记一样对待 data/ 文件夹
